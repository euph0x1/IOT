Experiments

## Abstract

This work presents a collection of Internet of Things (IoT) experiments demonstrating the integration of sensors, actuators, microcontrollers, and intelligent decision-making systems. The experiments include RGB LED color control using Arduino Uno and PWM, an automatic street-lighting system using an LDR and ESP32, a fire/smoke detection and alarm system using STM32, a motion detection system using Raspberry Pi Pico, and a TinyML-inspired LED decision system using ESP32. The systems were designed and tested using simulation platforms such as Tinkercad and Wokwi, enabling practical implementation of embedded programming concepts without requiring physical hardware. The experiments cover key IoT concepts including GPIO control, analog and digital sensor interfacing, ADC, PWM, threshold-based decision making, real-time monitoring, automation, and basic TinyML inference. Together, these implementations demonstrate how microcontrollers can process sensor inputs and produce appropriate real-time actions for applications in smart lighting, safety monitoring, security, automation, and edge intelligence.

1. RGB LED Color Display using TinkerCAD Arduino

Objective:
Design and implement an RGB LED control system using an Arduino Uno. Different colors are generated by varying the intensity of the red, green, and blue components using PWM.

Hardware / Tools:

Arduino Uno R3
RGB LED (Common Cathode)
3 × 220Ω resistors
Breadboard
Jumper wires
TinkerCAD Circuits

Working:
The Arduino uses PWM through pins 9, 10, and 11 to control the RGB components. The LED cycles through:

Red → Green → Blue → Yellow → Purple → Cyan → White

Each color is displayed for one second.

Concepts Covered:

Arduino programming
PWM
Digital output
RGB color mixing
Hardware-software integration

2. Automatic Street Light System using LDR and ESP32

Objective:
Develop an automatic street-lighting system that detects ambient light using an LDR and automatically switches an LED ON or OFF.

Hardware / Tools:

ESP32
LDR sensor module
LED
220Ω resistor
Jumper wires
Wokwi
Arduino IDE

Working:

The LDR continuously measures the surrounding light intensity.

Low Light → LED ON
High Light → LED OFF

The system uses a threshold value to make the lighting decision.

Pin Configuration:

Component	ESP32 Pin
LDR Analog Output	GPIO 34
LED	GPIO 15

Concepts Covered:

ESP32
LDR sensors
Analog sensor readings
Threshold-based decision making
GPIO control
Smart lighting
Energy-efficient IoT systems

3. STM32 Fire/Smoke Detection and Alarm System

Objective:
Design a safety monitoring system that continuously monitors an analog sensor value and activates an LED and buzzer when the value crosses a predefined threshold.

Hardware / Tools:

STM32 Nucleo / STM32 board
Potentiometer as simulated analog sensor
LED
Buzzer
Resistor
Wokwi

Working:

The analog sensor provides an input value to the STM32. The system compares this value with a threshold.

Sensor Value ≤ Threshold
        ↓
   LED OFF
   Buzzer OFF

Sensor Value > Threshold
        ↓
    LED ON
    Buzzer ON

Pin Configuration:

Component	Pin
Sensor	A0 / PA0
LED	D2 / PA1
Buzzer	D3 / PA2

Concepts Covered:

STM32
ADC
Analog sensor processing
Threshold-based detection
LED and buzzer actuation
Real-time safety monitoring

5. TinyML-Based LED Decision System using ESP32

Objective:
Implement a basic TinyML-inspired decision-making system on an ESP32. A generated input is transformed into a score, which is then compared against a threshold to control an LED.

Hardware / Tools:

ESP32
LED
Wokwi
Arduino programming language

Working:

The system generates a random input between 0 and 1 and calculates a score using a simple mathematical model.

Random Input
     ↓
Score Calculation
     ↓
Threshold Comparison
     ↓
 ┌───────────────┐
 │ Score > 0.5   │ → LED ON
 │ Score ≤ 0.5   │ → LED OFF
 └───────────────┘

The LED is connected to GPIO 2 and the decision process repeats every 500 ms.
